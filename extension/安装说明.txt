AI 知识收件箱浏览器扩展

Chrome 安装：
1. 打开 chrome://extensions
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本文件所在的 AI-Knowledge-Extension 文件夹

Edge 安装：
1. 打开 edge://extensions
2. 开启“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 选择本文件所在的 AI-Knowledge-Extension 文件夹

使用：
- 在网页中选中文字，右键选择“保存到 AI 知识库”
- 点击浏览器工具栏中的扩展图标，可确认标题、正文和来源后保存
- 在扩展弹窗点击“打开知识库”，可搜索、查看、删除和备份
- 保存时会在本地自动建议标签，也可手动修改；知识库支持按项目、标签筛选
- 重复的正文内容不会再次保存
- 网页中的标题、列表、粗体、链接和代码块会尽量保留为 Markdown
- 知识库中的“预览”可查看格式化后的内容，“编辑”保留 Markdown 原文
- 首页显示全部知识、近 7 天新增、累计预览和主要来源
- 支持按最新保存、最多预览或最近预览排序
- 多关键词搜索会综合标题、项目、标签和正文进行相关性排序
- 预览底部会推荐同项目、同标签或主题相近的知识
- 支持单条 Markdown 和当前筛选结果的批量 Markdown 导出
- 编辑知识时可用浏览器内置 AI 生成智能标题和摘要（需浏览器支持 Prompt API）
- 可切换“语义向量”搜索；向量在本地即时计算，不上传内容
- v1.1.0 起优先连接 Windows 桌面伴侣的共享 SQLite 数据库
- 首次连接会自动迁移原有浏览器数据；服务未运行时会明确显示浏览器本地模式
- 桌面伴侣会通过用户自己的 OneDrive 同步知识；知识库页面显示同步状态并支持立即同步
- 知识库顶部的“Ask 知识库”会先本地检索，再由支持 Prompt API 的浏览器内置 AI 综合并标注来源
- 快捷键 Ctrl+Shift+K 可打开扩展弹窗

数据仅保存在当前浏览器的扩展本地存储中。更换浏览器或卸载扩展前，请先导出 JSON 备份。
