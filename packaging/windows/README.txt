AI Knowledge Inbox __VERSION__
================================

安装
----
1. 解压整个 ZIP。
__INSTALL_STEP__
__SIGNING_NOTE__
3. 安装器会打开浏览器扩展页，并把扩展目录复制到剪贴板。
4. 开启开发者模式，选择“加载已解压的扩展”。
5. 在桌面 AI 中复制内容，按 Ctrl + ; 保存。

主要能力
--------
- Windows 桌面剪贴板采集
- Edge/Chrome 网页选区采集
- SQLite 本地知识库
- OneDrive 多设备同步
- Markdown、标签、项目与语义搜索
- Ask 知识库：本地检索、内置 AI 综合和引用来源

数据位置
--------
- 本地数据库：%LOCALAPPDATA%\AIKnowledgeInbox\knowledge.db
- OneDrive：Apps\AI Knowledge Inbox\knowledge-sync.json

卸载默认保留知识数据。
